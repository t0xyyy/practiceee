# Отдельные HTML-макеты

Шесть автономных HTML-макетов для визуальной демонстрации второго модуля.
Открывайте `home.html`, `register.html`, `login.html`, `apply.html`, `dashboard.html`, `admin.html` напрямую в браузере.
Формы и кнопки внутри макетов служат для оценки дизайна. Для **работающих** форм и сохранения в SQLite используйте основной проект через `START.bat`.
Вся стилистика общая с рабочими страницами, изображения локальные SVG. Контрольный размер мобильного окна 390 × 844 пикселя.
